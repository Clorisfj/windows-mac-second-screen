# CFlow 开发与验收

本目录是 CFlow 应用开发，不是重新部署 Sunshine/VDD 的任务。先读 README.md；Mac 接手再读 Mac交接.md。

- 保留原 Moonlight、Sunshine、Deskflow 配对与物理主屏，不卸载、不重置、不降低系统防护。
- Windows UI 普通权限，按需启动受限管理员助手；不要把整个 UI 改回 requireAdministrator，也不要自动创建提权计划任务。
- Mac 保持 LSUIElement、单色菜单栏缩略图与瞬态弹出面板；菜单栏按钮支持左键开关面板、右键打开含退出项的菜单。接收端随手动启动运行，不依赖先点开弹窗。登录启动默认关闭。
- 控制通道必须证书固定、密钥验证、限定动作；禁止全局忽略证书、明文密钥落盘或任意远程 shell。
- 配对码/钥匙串/DPAPI 数据、证书私钥、真实运行日志不能提交。测试证书仅为本地临时夹具。
- Mac 必须在真实 Mac 构建验证；先修真实编译错误，再做双端实测。不能把进程存在当作串流和键鼠已经可用。
- UI 变化核对主面板与设置；协议变化运行 Windows tests/run.ps1，并在 Mac 重测认证与失效配对。
- Mac 发起模式/参数变更是排队给 Windows 主控的请求；不要直接启动客户端后把 Windows 端遗漏。两端模式必须以确认结果为准。
- 修复仅限此目录；不要顺手改根目录通用部署指南。交付时写清哪些已测、哪些待另一端验证。
