## 2026-11-11 管理员助手未就绪修复

- 现场日志反复出现“已关闭 Safe handle”；助手在接管模式前退出。隔离复现确认：BeginWaitForConnection 的 AsyncWaitHandle 在 EndWaitForConnection 前被释放会关闭仍在使用的句柄，甚至导致异步回调异常。
- 改为检查待处理连接完成状态，等待期间继续检查所属 UI 进程是否存活；不手动释放框架拥有的异步等待句柄。保留管道 ACL、请求 PID 校验和动作白名单。
- 助手只有真正接管模式操作后才在退出时恢复普通模式，单纯启动、ping 或启动失败不会再停止现有软件。错误日志记录完整异常，启动失败提示附助手退出代码。
- 新增 tests/run-admin.ps1：10 项实测通过，包含所属进程、空闲等待、多次连接、未知动作、其他进程拒绝、拒绝后重连、正常退出和 ping 不触发系统收尾。
- 新增 tests/run-helper.ps1：在 private/helper-probe 中以匹配路径的测试拥有者启动实际构建的 CFlow.Helper.exe，仅发送 ping/shutdown，允许验证实际按需提权链路而不操作显示/服务。

## 2026-11-11 IP 配对与双端请求升级

- 配对入口改为输入 Mac 局域网 IP。Mac 在本机开启两分钟配对窗口，双方通过证书指纹及先承诺后揭示的随机挑战生成同一 6 位数字。Mac 本机批准后才返回控制密钥，Windows 后续请求固定首次证书指纹。已有 DPAPI/钥匙串数据继续使用。
- Windows 设置页保持轮询；Mac 发起的请求收到 running/done/failed 回执。预设或 Windows 本机操作失败时，向 Mac 返回具体错误，不再误报为 Mac 离线。
- 助手初始化期间发送状态保活；停止模式时远端离线不阻止本机收尾。设置保存序列化，避免临时文件并发写入。离线检查期间点击设置会等待检查结束后打开。
- Mac 齿轮切换到同一菜单栏面板内的设置视图，移除独立 Settings scene 与外观说明行。接收端就绪和 Windows 已认证在线分别维护；离线不允许排队切换，等待期间失联会结束请求并显示错误。
- Windows 两个程序构建通过。tests/run.ps1 的 30 项测试、tests/run-admin.ps1 的 10 项测试均通过。tests/run-helper.ps1 另外通过实际构建助手的启动、空闲后通信、退出三项检查。
- 新增的实际 TLS 测试覆盖 IP 配对、批准前无密钥、证书变化拒绝、拒绝配对、错误请求 ID、控制密钥加密保存，以及 Windows 本机请求失败的结果回传。
